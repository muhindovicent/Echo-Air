# Echo & Air — Phase 2 visual preview

This is a **concept prototype**, separate from the existing production-facing `index.html`.

## Open the preview

1. In VS Code, switch to the `redesign/phase-02-visual-preview` Git branch (fetch first if needed).
2. Open `preview/index.html` using the Live Server extension, **or** start a Python HTTP server from the repository root and visit `http://localhost:5500/preview/`.
3. Check at both desktop and phone widths using your browser's responsive device mode.

No npm, React, environment variables or backend is required to see this prototype.

## What this phase provides

- A modern responsive homepage concept using cream, near-black and accent orange-red.
- A typographic editorial hero, inspiration gallery, campaign/story section and footer.
- Mobile navigation that opens/closes with a button; Escape key also closes the menu.
- A gallery category filter with accessible pressed-state and result count.
- Accessible skip link, focus indicators and reduced-motion styling.

## What this phase intentionally does not provide

- Real products, pricing, real stock or licensed brand photography.
- A product details page, wish list, cart, orders, payments, shipment or customer accounts.
- Confirmed Echo & Air store information or company contact details.

The photography is illustrative and sourced from the **existing prototype URLs**. It must be reviewed and replaced with authorized brand photography before a public launch.

## Manual acceptance checklist

- [ ] `preview/index.html` opens without 404 errors for its local CSS or JS.
- [ ] At 375px width the hero fits and the page does not scroll horizontally.
- [ ] Mobile menu opens; links navigate to the correct page section; Escape closes.
- [ ] Keyboard navigation and visible focus styles work.
- [ ] Selecting Apparel shows four gallery looks; Footwear & accessories shows two; All shows six.
- [ ] At 1440px width the hero is split in two columns and the collection grid has three columns.
- [ ] Text and images do not overlap at 375px, 768px and 1440px.
- [ ] Verify the available internet access loads the sample images and Google fonts.
- [ ] Review with real stakeholders for tone, products and photography before promoting this to the main homepage.

## Next milestone

After stakeholder review, agree the canonical homepage direction, source real brand assets and product information, and migrate accepted sections into the final storefront. The legacy homepage is **not** automatically replaced.
